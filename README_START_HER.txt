GRAFF ENTERTAINMENT – HJEMMESIDE v5.3 (1. november 2026)

18 separate sider (dansk og engelsk) samt rodforside. Ingen app er endnu lanceret:
behold status På vej / Coming soon indtil faktisk lancering.

ÆNDRINGER FRA v5.2
- Fjernet markeringen UDKAST / DRAFT på Sugar Sorters privatlivspolitik.
- Erstattet med neutral oplysning om, at spillet ikke er lanceret, og at
  databehandlingen beskrives som planlagt.
- Alle øvrige godkendte hjemmeside- og privatlivstekster bevaret.
- Cloudflare D1 er beskrevet som planlagt, ikke som en implementeret backend.

PUBLICERING
1. Pak ZIP-filen ud.
2. Upload indholdet af den udpakkede mappe til roden på GitHub Pages repository.
3. Settings -> Pages -> Deploy from a branch -> main -> /(root).
4. Kontroller den offentlige adresse i en rigtig browser på mobil, tablet og PC.

FØR SPILLENES LANCERING
Kontroller, at App Store oplysninger og privatlivspolitikker afspejler den faktiske
implementerede databehandling og købsrettigheder, herunder Cloudflare D1,
24-måneders sletning og bevaring af købte kreditter i Sugar Sorter.

Den låste originale v5 og versionsarkiverne v5.1/v5.2 er bevaret.
